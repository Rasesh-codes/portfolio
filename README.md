# Personal Developer Portfolio 💻

My personal single-page portfolio website designed to introduce myself, showcase my skills, feature my project **Sentinel AI**, and demonstrate basic JavaScript DOM manipulation logic with an interactive GPA calculator.

---

### 🎨 Design & Aesthetic
- **Theme:** Warm cream/paper aesthetic (`#fbf8f3`) with charcoal typography and rust accents.
- **Layout:** Clean, responsive, and lightweight—no bloated UI frameworks or heavy external libraries.

---

### 🛠️ Built With
- **HTML5:** Semantic structure (`<header>`, `<main>`, `<section>`, `<footer>`).
- **CSS3:** Custom properties (variables), CSS Grid, Flexbox, and custom styling.
- **Vanilla JavaScript:** DOM manipulation for the dynamic Semester GPA Calculator.
